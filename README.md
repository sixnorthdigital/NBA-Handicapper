# NBA Handicapper

NBA game cards with DraftKings lines, and matchup pages with team grades, form, rest and the 2-year head-to-head (against the spread and the total). Data comes from ESPN's public feeds.

Split out of the Hockey Handicapper so each sport is its own app.

Run locally: `npm start`, then open http://localhost:3000. Deploy on Render as a Node web service with start command `npm start`.
